## Full description (max 4000)

```
Firefly Shortcuts lets you add the transactions you repeat all the time to your own Firefly III server with a single tap. Set them up once, then post them from a home screen widget or from the app, with no forms to fill in.

Firefly III is a free, open-source personal finance manager that you host yourself. Firefly Shortcuts is an unofficial companion app: it isn't made by or affiliated with the Firefly III project, and you need your own Firefly III server to use it.

HOW IT WORKS
• Connect to your Firefly III server with a personal access token or OAuth.
• Sync your accounts, categories, budgets, bills, piggy banks and tags.
• Create shortcuts: a daily coffee, lunch on work days, a transfer to savings.
• Tap ▶ on the widget. The transaction is posted in the background, and the button shows an hourglass, then a check mark or an X.

FEATURES
• Withdrawals, deposits and transfers.
• Optional category, budget, bill, piggy bank, tags and description on every shortcut.
• An emoji icon for each shortcut, so the widget is easy to scan.
• Searchable account lists, for servers with many accounts.
• A warning on shortcuts that use an account you've since deactivated or deleted.
• Safe retries: if the network drops, the app tries again without ever creating a duplicate transaction.
• Runs from the app too, with a confirmation showing exactly what will be sent.
• Light and dark theme, with your wallpaper's colors on Android 12 and newer.

PRIVACY
• The app only talks to the Firefly III server you enter, over HTTPS.
• No analytics, no ads, no tracking. Nothing is sent to the developer.
• Your sign-in is stored encrypted with a key that never leaves your phone.

OPEN SOURCE
Firefly Shortcuts is free and open source under the MIT license. Source code, setup help and issue tracker: github.com/mcanyucel/firefly-shortcuts

REQUIREMENTS
• Your own Firefly III server (tested with version 6), reachable over HTTPS.
• Android 8.0 or newer.
```
